# Contributing to ChaiFrontend

Thank you for your interest in contributing to ChaiFrontend! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/ChaiFrontend.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes
6. Commit your changes: `git commit -m 'Add some feature'`
7. Push to the branch: `git push origin feature/your-feature-name`
8. Open a Pull Request

## Development Setup

1. Install Flutter SDK (>=3.0.0)
2. Install dependencies: `flutter pub get`
3. Run the app: `flutter run`

## Code Style

- Follow the official [Dart Style Guide](https://dart.dev/guides/language/effective-dart/style)
- Use `flutter format` to format your code
- Run `flutter analyze` to check for issues
- Ensure all linter rules in `analysis_options.yaml` are followed

## Testing

- Write tests for new features
- Run tests with `flutter test`
- Ensure all tests pass before submitting a PR

## Pull Request Guidelines

1. Update the README.md with details of changes if applicable
2. Update the documentation for any changed functionality
3. The PR should work for the supported Flutter versions
4. Add tests for new features
5. Ensure the code follows the project's code style
6. Write clear, descriptive commit messages

## Code of Conduct

- Be respectful and inclusive
- Welcome newcomers and encourage diverse contributions
- Focus on what is best for the community
- Show empathy towards other community members

## Reporting Bugs

When reporting bugs, please include:

1. Flutter version (`flutter --version`)
2. Device/emulator information
3. Steps to reproduce the bug
4. Expected behavior
5. Actual behavior
6. Screenshots if applicable

## Feature Requests

Feature requests are welcome! Please provide:

1. A clear description of the feature
2. Why this feature would be useful
3. How it should work
4. Any examples or mockups

## Questions?

Feel free to open an issue with your question or reach out to the maintainers.

Thank you for contributing to ChaiFrontend!
